# Plan: Устранение механистичности и повторяющихся паттернов в ответах Ники

## Диагноз проблемы

Текущая архитектура способствует механистичности по нескольким причинам:

1. **Структурная жёсткость стоек.** Каждая стойка предписывает одну и ту же структуру: «отрази → задай вопрос». `explore` говорит «отрази то, что услышала, и задай ОДИН открытый вопрос» — это почти рецепт для схемы «Понимаю [X]. Интересно, [Y]?».
2. **Слабая вариативность в зачинах.** Запреты есть только на конкретные фразы («Я здесь», «Я слышу тебя»), но нет позитивных альтернатив и указания менять структуру ответа от реплики к реплике.
3. **Инструкция `validate_level`** задаёт объём отражения, но не форму — модель каждый раз выбирает лёгкий путь: «Понимаю, что ты чувствуешь X».
4. **Ни в `orchestrator.txt`, ни в стиле `balanced`** нет явного запрета на конструкцию «Понимаю + Интересно», хотя в `gentle` она упомянута.

## Файлы для изменения

### 1. `backend/app/agents/prompts/orchestrator.txt` — Основной промпт

**Что добавить/изменить:**

Добавить после строки 9 (после списка запрещённых фраз) новый блок с позитивными альтернативами и правилом структурной вариативности:

```
## Как не звучать шаблонно

Следи за структурой своих ответов. Если в предыдущей реплике ты начала с отражения и закончила вопросом — в следующей используй другой ход:
- начни с наблюдения, а не с подтверждения («Тут есть что распутать» вместо «Понимаю»)
- начни с метафоры или образа
- начни с прямого ответа на то, что прозвучало между строк
- используй риторический вопрос как зачин
- начни с короткого резюме сути («Похоже, речь о том, что...»)
- начни с конкретного действия или практики
- начни с признания сложности без клише («Тут нет простого ответа»)

Никогда не используй одну и ту же схему два раза подряд. Схема — это комбинация из 2-3 элементов (зачин + способ отражения + тип завершения). Меняй хотя бы один элемент.
```

## Риски и mitigation

- **Риск:** Модель станет чрезмерно разнообразной и потеряет терапевтическую последовательность.
  - **Mitigation:** Правило — менять хотя бы один элемент структуры, а не все сразу. Терапевтическая функция (отражение, углубление) сохраняется, меняется только форма.
- **Риск:** Увеличение длины системного промпта → больше токенов → выше стоимость.
  - **Mitigation:** Добавления суммарно ~200-300 символов — пренебрежимо на фоне текущего промпта.
