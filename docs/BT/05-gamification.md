# 05. Геймификация: Псевдонимы, Лидерборд, Микронаграды

## 5.1 Псевдонимы

### Назначение
Псевдоним служит анонимизации в лидерборде. Пользователь не обязан раскрывать имя или email.

### Типы псевдонимов

#### Тип 1: Генерируемый (по умолчанию для новых пользователей)

Формат: `[Прилагательное] [Существительное] [Число 10–99]`

Пример: *«Вечно Смущённый Енот 42»*, *«Неожиданно Мудрый Пингвин 17»*

**Словари** (хранятся в `data/`):
- `pseudonym_adj.txt` — 200+ прилагательных с эмоциональным/характерным оттенком:
  `Вечно Смущённый`, `Неожиданно Мудрый`, `Тихо Паникующий`, `Смело Мечтающий`,
  `Слегка Растерянный`, `Упрямо Оптимистичный`, `Безмятежно Тревожный`, ...
- `pseudonym_nouns.txt` — 200+ животных и образов:
  `Енот`, `Пингвин`, `Лисица`, `Бобёр`, `Ёж`, `Кот`, `Выдра`, `Сова`, ...
- Число — random.randint(10, 99).
- Коллизии: при совпадении с существующим псевдонимом — перегенерировать (до 5 попыток).

**Алгоритм генерации (`pseudonym_service.py`):**
```python
async def generate_pseudonym() -> str:
    adj = random.choice(ADJECTIVES)
    noun = random.choice(NOUNS)
    num = random.randint(10, 99)
    candidate = f"{adj} {noun} {num}"
    if not await pseudonym_exists(candidate):
        return candidate
    # рекурсия до 5 раз
```

#### Тип 2: Ироничный (при отказе от имени)

Если пользователь выбирает «Не хочу псевдоним» или обращение «Вы»:
- Система молча назначает псевдоним формата: `ЯВЗРОСЛЫЙ_#[случайный 3-значный номер]`
- Пример: `ЯВЗРОСЛЫЙ_#354`, `ЯВЗРОСЛЫЙ_#817`
- В лидерборде этот псевдоним **виден по умолчанию**.
- Пользователь может скрыть его одним чекбоксом «Скрыть меня из рейтинга»,
  который показывается сразу после назначения псевдонима.

#### Тип 3: Пользовательский (опционально)

В PseudonymModal — поле ввода (max 30 символов). Ограничения:
- Нельзя использовать ненормативную лексику (базовый фильтр).
- Нельзя использовать email или номер телефона (regex-проверка).
- Нельзя выбрать псевдоним, совпадающий с существующим.

---

### Когда показывается PseudonymModal

1. Первый раз, когда пользователь получает результат игры (сценарий A или B).
2. Если пользователь уже авторизован — псевдоним привязывается к `User.id`.
3. Если анонимен — псевдоним хранится в `UserPseudonym` с `anonymous_session_id`.
4. При регистрации позже — псевдоним мигрирует на аккаунт автоматически.

## 5.2 Лидерборд

### Механика рейтинга

**«Победи Нику»** — игра на «выносливость». В рейтинге выигрывает тот, кто продержался
**больше ходов**, прежде чем система угадала. Это мотивирует на повторные игры.

Формула очков: `score = moves_count * 10 - (time_seconds / 10)`
- При одинаковом числе ходов побеждает тот, кто потратил меньше времени.
- При Сценарии B (пользователь победил): `score = moves_count * 10 + 50` (бонус за победу).
- При Сценарии A (Ника угадала): стандартный score без бонуса.

### Таблица лидеров (UI)

- Топ-20 записей.
- Колонки: `#`, `Псевдоним`, `Ходов`, `Очков`, `Победитель?` (🏆 / —).
- Текущий пользователь подсвечивается (цвет `warm-300` строка).
- Обновляется в реальном времени (polling раз в 30 секунд или SSE).

### Хранение (`LeaderboardEntry`)

```
id: uuid
pseudonym_id: uuid
score: int
moves_count: int
time_seconds: int
scenario: A | B
topic: str | null       ← только если сценарий A
created_at: datetime
is_visible: bool        ← false если пользователь скрыл себя
```

### Доступность лидерборда

- Лидерборд виден всем (без авторизации) на странице `/game` после любого завершения.
- Отдельная страница `/leaderboard` — публичная.
- Ссылка на лидерборд — в шапке игрового экрана.

## 5.3 Микронаграды (Дофаминовые механики)

### Конфетти (Сценарий A)

- Библиотека: `canvas-confetti` (лёгкая, ~14kb gzip).
- Запуск: сразу после появления финального сообщения Ники.
- Длительность: 5 секунд.
- Параметры: `particleCount: 80, spread: 70, origin: {y: 0.6}`.
- Цвета: `primary-400`, `warm-300`, белый.
- Звуков нет.

### Джекпот-анимация (Сценарий B)

Основная анимация описана в [06-frontend-ux.md](./06-frontend-ux.md) (занавес).
После поднятия занавеса:
- Таймер результата: «Ты продержался **[N] ходов** за **[MM:SS]**».
- Строка текущего места в рейтинге: «Ты на **#X** месте!» (запрос к API).
- Кнопка «Сыграть снова» — крупная, `primary-500`.
- Кнопка «Поделиться» (опционально, v2) — копирует текст в буфер: *«Я победил Нику за X ходов! Попробуй: [ссылка]»*

### Прогрессивное вовлечение

- На ходу 5: краткое сообщение от Ники: *«Интересно... ты непрост(а)»* (статическая фраза).
- На ходу 9: *«Немного осталось... или нет?»*
- На ходу 11: *«Последний шанс угадать!»* — появляется как системная плашка под вопросом.

## 5.4 Приватность и настройки

При первом показе PseudonymModal внизу — чекбокс:
```
☑ Показывать мой результат в рейтинге
```
По умолчанию — включён. Снятие флага → `is_visible = false` в `LeaderboardEntry`.

Зарегистрированный пользователь может изменить видимость в настройках профиля
(новый раздел «Игровой профиль» → «Скрыть из рейтинга»).
