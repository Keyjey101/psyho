# 04. Механика Основной Игры «Победи Нику»

## 4.1 Структура игровой сессии

```
GameSession
  id: uuid
  anonymous_session_id: str      ← из cookie, до авторизации
  user_id: uuid | null           ← если авторизован
  status: pending | active | finished_a | finished_b | crisis_interrupted
  move_count: int                ← количество ходов пользователя (0..12)
  answers: JSON                  ← [{question, choices, chosen_index, move_num}]
  landing_answers: JSON          ← предразогрев с лендинга (опционально)
  dominant_topic: str | null
  final_confidence: float | null
  pseudonym_id: uuid | null
  created_at: datetime
  finished_at: datetime | null
```

---

## 4.2 Игровой экран

**URL:** `/game` (или `/game/{session_id}` для возобновления)

**Элементы интерфейса (сверху вниз):**

1. **Шапка:** Лого «Ника» (🌸) + текст «Победи Нику» + счётчик ходов «Ход 3/12».
2. **Прогресс-бар:** тонкая линия под шапкой, заполняется по мере ходов.
3. **Область сообщений:** последнее сообщение Ники (крупный шрифт, тёмный фон).
4. **Варианты ответа:** 3 кнопки-карточки (A / B / C).
5. **Нижняя строка:** псевдоним пользователя (мелко) + кнопка «Сдаться» (выход).

---

## 4.3 Поток одного хода

```
Пользователь тапает вариант
  → UI: кнопка выбора подсвечивается, остальные блокируются
  → WS: {"type": "answer", "choice": 2, "session_id": "..."}
  → UI: показывается ThinkingSpinner
  ← WS: {"type": "thinking"}        ← немедленно от сервера
  ← WS: {"type": "question", "text": "...", "choices": ["A","B","C"], "move": 4}
       ИЛИ
       {"type": "result", "scenario": "A|B", "confidence": 0.87,
        "topic": "anxiety", "moves": 5, "topic_label": "тревога"}
  → UI: ThinkingSpinner исчезает
  → UI: текст Ники появляется с эффектом печати (typewriter)
```

---

## 4.4 Эффект печати (Typewriter)

- Символы появляются со скоростью **30 символов/секунду**.
- Нет мигающего курсора (или однопиксельное мигание 0.5s interval, цвет `primary-400`).
- Варианты ответа появляются **после завершения** печати текста вопроса.
- На ходах 10-12: если РО сформировал «провокационный» вариант, он помечается
  тонкой рамкой `warm-500` (не акцентировать чрезмерно).

---

## 4.5 Сценарий A: «Ника угадала»

**Триггер:** `analysis.confidence >= 0.80`

**Последовательность:**

1. РО получает `ready=true` от АА.
2. АВ генерирует финальное сообщение:
   ```
   «Мне кажется, мы затронули что-то важное.
   Похоже, тебя беспокоит [topic_label]? Это нормально. ✨»
   ```
   Ограничение: 300 символов, без диагнозов, с названием темы на русском.
3. Пауза 1 секунда после печати.
4. Появляются 2 кнопки:
   - **«Да, это про меня!»** → онбординг (см. ниже)
   - **«Нет, сыграем снова!»** → сброс сессии

**При «Да, это про меня!»:**
- Показывается `ConfettiLayer` (5 секунд, лёгкое конфетти).
- Показывается онбординг-карточка:
  ```
  «Ника готова поддержать тебя глубже.
   Создай аккаунт — это бесплатно.»
  [Войти через email]  [Позже]
  ```
- Если пользователь уже авторизован → карточка «Продолжить разговор с Никой?» → переход в
  основной чат (`/chat`) с предзаполненным `continuation_context` от игровой сессии.

**При «Нет, сыграем снова!»:**
- `GameSession` обновляется: `status = "pending"`, `answers = []`, `move_count = 0`.
- Новые априорные вероятности АА сбрасываются.
- Пользователю показывается первый вопрос новой игры (без перезагрузки страницы).

---

## 4.6 Сценарий B: «Пользователь победил»

**Триггер:** `move_count >= GAME_MAX_MOVES` (достигнут лимит 12 ходов)  
ИЛИ: `confidence < 0.40` (АА не смог определить доминирующую тему)

**Последовательность:**

1. РО фиксирует «победу пользователя».
2. АВ генерирует сообщение «признания поражения» (≤300 символов):
   ```
   «Хм, ты меня перехитрил(а)! 😄
    Похоже, ты умеешь держать карты при себе.»
   ```
3. **Анимация занавеса** (см. [06-frontend-ux.md](./06-frontend-ux.md)):
   - Экран затемняется.
   - SVG-занавес опускается сверху вниз.
   - На занавесе крупно: **«БРАВО! Ты победил(а) Нику за [N] ходов. ДЖЕКПОТ!»**
4. Под надписью:
   - Таймер: **«Время: [MM:SS]»** — реальное время сессии.
   - Кнопка **«Поднять занавес»** (или тап по экрану).
5. При поднятии занавеса → таблица лидеров (см. [05-gamification.md](./05-gamification.md)).

---

## 4.7 Провокационные варианты на ходах 10–12

При приближении к лимиту АГД получает инструкцию генерировать более острые формулировки,
чтобы ускорить набор уверенности АА:

- Вопросы становятся более прямыми: не «когда бывает стресс», а «прямо сейчас что-то давит?»
- Один из трёх вариантов — заведомо «честный» (сложно выбрать, если скрываешь).
- Если после хода 10 confidence всё ещё < 0.60 — РО принудительно завершает по Сценарию B.

---

## 4.8 Кнопка «Сдаться»

- Видима с первого хода, мелкая, в нижней строке.
- При нажатии — диалог подтверждения: «Уверен(а)? Прогресс потеряется.»
  - «Да» → сессия завершается как Сценарий B (moves = текущее число, no jackpot).
  - «Нет» → продолжить.

---

## 4.9 Восстановление сессии

- При возврате на `/game` с активной сессией (по cookie `game_session_id`) —
  игра продолжается с текущего хода.
- Если сессия завершена (status finished_a/b) → предложение начать новую игру.
- Сессия живёт 2 часа без активности, затем автоудаляется (cron или background task).
