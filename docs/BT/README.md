## Обзор продукта

**«Победи Нику»** — вирусная мини-игра на лендинге психологической платформы. Пользователь
отвечает на вопросы от ИИ-психолога Ники, а скрытый агент-анализатор строит психологический
профиль. Игра завершается двумя сценариями:
- **«Ника угадала»** — переход к онбордингу и подписке.
- **«Пользователь победил»** — джекпот-анимация, запись в лидерборд, приглашение сыграть снова.

## Ключевые ограничения

| Параметр | Значение |
|----------|---------|
| Максимум сообщений пользователя | 12 |
| Максимум токенов на ответ Ники | 300 символов / ~220 токенов |
| Порог уверенности АА для завершения | ≥ 0.80 |
| Таймаут вызова LLM | 5 секунд |
| Бюджетный лимит LLM | $50 / месяц |
| Лимит лендинг-теста перед переводом в игру | 5 ответов или 60 секунд |

## Архитектурные решения

- Все генерации текста — исключительно через внешний LLM API (ZAI / OpenAI / Anthropic).
- Локальные ML-модели не используются. GPU не требуется.
- Fallback при недоступности API — статический набор заготовленных фраз.
- Новая функциональность добавляется поверх существующего FastAPI + React стека (см. CLAUDE.md).

## Важное решение по безопасности

Раздел об «специальных символах-разделителях» (`[XOR-9862]`, `[TRG-451B]`, `[NIKA-SYS]`,
`[NIKA-REQ]`) **исключён из настоящего ТЗ**. Конструкция «пользователь не видит токен,
но бэкенд обязателен его проверяет, агент никогда не раскрывает его назначение» не является
легитимным механизмом безопасности и противоречит принципам прозрачного ИИ-продукта.
Валидация ответов агентов реализуется через стандартные методы (см. раздел «Validator Loop»
в [02-agents.md](./02-agents.md)).
